
Experiments
===========


We will organize the project in a repository on GitHub. Please clone this repository and create a folder in the Godot folder for your the game that you will test.

.. code-block:: bash

    git clone https://github.com/mastainvin/Xumes-Examples.git



.. note::

    Please use the github issues to report bugs (it's easier to track them). I added a template for the issues, please use it. `Issues <https://github.com/mastainvin/Xumes-Examples/issues>`_ `Project page <https://github.com/users/mastainvin/projects/4>`_ (ask to be added if it's not the case).
